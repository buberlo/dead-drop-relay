# Dead Drop Relay

> Pass small physical items between friends using geofenced QR handshakes.

A local-first mobile app for sharing packages, library books, or forgotten keys by creating dead drops tied to a location and a secret question. Recipients can claim the item only by scanning a QR code near the drop and answering correctly.

## Features
- QR-coded geofenced drop creation
- Secret-question access with one-time codes
- Pictogram-only item metadata to save space
- Handshake audit trail with no cloud account

## Stack
- React Native
- SQLite
- QRCode

## Getting started
```
npm install && npm start
```
